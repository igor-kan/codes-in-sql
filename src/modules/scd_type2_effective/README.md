# Bi-Temporal SCD Type-2 Dimension Store (`scd_type2_effective`)

> Category: **Data Warehousing SQL** | Language: **SQL (ANSI / SQLite3)**

## Overview

Slowly Changing Dimension Type-2 slowly-evolving entity ledger enforcing single active open-ended version and contiguous non-overlapping history.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- every entity has at most one active current_flag = 1 open interval
- consecutive effective intervals satisfy next.valid_from == prev.valid_to
- point-in-time snapshot queries return at most 1 row per entity
