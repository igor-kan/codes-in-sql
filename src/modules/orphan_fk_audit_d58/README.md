# Referential Integrity Orphan Child Auditor View (`orphan_fk_audit_d58`)

> Category: **Data Quality Auditing** | Language: **SQL (ANSI / SQLite3)**

## Overview

Discovers dangling child rows whose foreign-key references fail to match any parent record via LEFT JOIN NULL filtering.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Valid referential integrity leaves 0 orphan rows in audit view cleanly.
