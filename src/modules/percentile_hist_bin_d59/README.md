# Equi-Width Numeric Histogram Bin Aggregation View (`percentile_hist_bin_d59`)

> Category: **Distribution SQL** | Language: **SQL (ANSI / SQLite3)**

## Overview

Assigns continuous measurements into fixed-width integer bins and verifies bucket sum reproduces total row count cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(B)` |

## Mathematical & Safety Invariants

- Sum across histogram bins matches raw sample count cleanly.
