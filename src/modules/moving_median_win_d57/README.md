# Self-Join 3-Tick Centered Sliding Window Extrema View (`moving_median_win_d57`)

> Category: **Window Joins** | Language: **SQL (ANSI / SQLite3)**

## Overview

Computes bounded 3-period window minima and maxima cleanly via timestamp self-range BETWEEN join predicates.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Every tick value falls bounded inside its local [win_min, win_max].
