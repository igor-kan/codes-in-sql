# Ordered Multi-Stage Conversion Funnel (`funnel_conversion_cte`)

> Category: **Product Funnel Analytics** | Language: **SQL (ANSI / SQLite3)**

## Overview

Strict temporal ordering conversion attribution funnel (view -> cart -> checkout -> purchase) enforcing stage monotonicity per user.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- converted step counts satisfy n_view >= n_cart >= n_checkout >= n_purchase
- users completing stage k out-of-order before stage k-1 are excluded
- conversion ratios stay bounded within [0.0, 1.0]
