# Row-Number Difference Consecutive Streak Detector (`gaps_islands_streak_d56`)

> Category: **Sequence Analytics** | Language: **SQL (ANSI / SQLite3)**

## Overview

Groups contiguous daily user login sequences into islands via (day - ROW_NUMBER()) invariant keys without procedural loops.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Maximum island length is bounded by total distinct active days.
