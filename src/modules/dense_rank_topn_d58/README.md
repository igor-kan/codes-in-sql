# Per-Department Top-K DENSE_RANK Selector View (`dense_rank_topn_d58`)

> Category: **Window Ranking** | Language: **SQL (ANSI / SQLite3)**

## Overview

Extracts top-2 distinct salary tiers per department using tie-preserving DENSE_RANK() partition ordering cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Every retained row strictly satisfies dr <= 2.
