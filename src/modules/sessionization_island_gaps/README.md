# Clickstream Gap-and-Island Sessionizer (`sessionization_island_gaps`)

> Category: **Event Stream Analytics** | Language: **SQL (ANSI / SQLite3)**

## Overview

SQLite window-function LAG + running SUM sessionizer partitioning user event streams across idle timeout gaps (> 1800s).

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- every user session_id starts at 1 and increments monotonically without skips
- session_end_ts >= session_start_ts for every aggregated session
- sum of session event counts equals total input clickstream event count
