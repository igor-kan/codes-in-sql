# Period-Over-Period LAG Delta & Growth View (`yoy_lag_growth_d58`)

> Category: **Time-Series Growth** | Language: **SQL (ANSI / SQLite3)**

## Overview

Computes exact period delta against immediate prior quarter using SQL LAG() window lookback cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Cumulative period-to-period deltas equal final_rev - initial_rev identically.
