# Overlapping Time Interval Coalescing (`interval_coalesce_merge`)

> Category: **Temporal / Scheduling SQL** | Language: **SQL (ANSI / SQLite3)**

## Overview

Coalesces overlapping or adjacent [start_ts, end_ts] reservations using window prefix-max envelope partitioning without procedural loops.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- merged intervals are strictly disjoint: next.start_ts > prev.end_ts
- total covered span of merged intervals never exceeds sum of raw durations
- every raw interval lies completely inside at least one merged output interval
