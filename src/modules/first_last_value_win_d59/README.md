# FIRST_VALUE & LAST_VALUE Ordered State Snapshot View (`first_last_value_win_d59`)

> Category: **Window Trajectory** | Language: **SQL (ANSI / SQLite3)**

## Overview

Extracts initial and latest terminal statuses per ticket using explicit full-partition window frame bounds.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Every ticket records non-null opening and closing terminal status.
