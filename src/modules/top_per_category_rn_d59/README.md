# ROW_NUMBER() Deterministic Top-1 Product Per Store (`top_per_category_rn_d59`)

> Category: **Top-N Per Group** | Language: **SQL (ANSI / SQLite3)**

## Overview

Ranks items descending by revenue inside each store with lexicographic SKU tie-breaker emitting exactly one winner per store.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Selected store row count strictly matches DISTINCT store_id count.
