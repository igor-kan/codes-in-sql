# RFM Customer Recency-Frequency-Monetary Tier View (`rfm_customer_tier_d57`)

> Category: **Customer Analytics** | Language: **SQL (ANSI / SQLite3)**

## Overview

Aggregates customer purchase histories into recency day, order frequency, and monetary spend tiers cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(U)` |

## Mathematical & Safety Invariants

- Every customer total spend matches sum of individual ticket charges.
