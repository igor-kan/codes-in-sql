# Expected Schedule vs Delivered Shipment Gap Audit (`anti_join_missing_d59`)

> Category: **Reconciliation SQL** | Language: **SQL (ANSI / SQLite3)**

## Overview

Identifies missing expected shipment legs absent from actual delivery confirmations using SQL LEFT JOIN IS NULL anti-join.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Count of missing shipments + matched shipments equals expected manifest total.
